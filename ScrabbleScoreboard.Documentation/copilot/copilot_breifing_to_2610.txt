Starliner Briefing
Scrabble Scoreboard PoC
Period: 22/10/2026 - 25/10/2026
Executive Summary

The Scrabble Scoreboard project transitioned from a technology proving exercise into a largely complete reference implementation of a modern microservice architecture.

Major objectives achieved:

✅ RabbitMQ messaging proven

✅ PostgreSQL persistence introduced

✅ EF Core migrations established

✅ Seed data strategy implemented

✅ Database-backed leaderboard implemented

✅ Docker/containerisation concepts understood and evaluated

✅ GitHub Copilot-assisted test generation evaluated successfully

The remaining project work is primarily deployment, refinement and demonstration preparation rather than technology discovery.

Key Observation

The most valuable outcome of the period was not a piece of code.

It was reinforcement of the emerging principle:

Code is cheap.

Context is expensive.


The technologies investigated (RabbitMQ, EF Core, PostgreSQL, Docker, Copilot) were valuable primarily because they helped identify reusable architectural patterns, workflow models and opportunities for future Cascata products.
